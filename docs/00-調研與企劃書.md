## 三、劇情大綱：《勇闖屍骨山——尋藥之旅》

- **背景**：太醫署瘟疫橫行，民間又傳黑心藥商以未經炮製的生烏頭、甚至公告禁用的硃砂與含馬兜鈴酸偽藥牟利。年輕藥師**沈青囊**（受神農遺志所託，攜「赭鞭」與「神農藥鼎」）孤身踏入傳說中埋骨無數、卻生長著救命回陽良藥「**熟附子**」的**屍骨山**。
- **起（山門殘碑）**：開頭簡短水墨字幕交代目的——「毒藥苦口利於病，然未經炮製，良藥亦成索命之毒。」玩家在山門石碑前熟悉移動、赭鞭驗毒與清除一處「硃砂禁藥瘴氣」。
- **承（瘴氣藥谷 — 小怪遭遇戰）**：深入屍骨棧道，遭遇三波各具藥性特色的小怪（生半夏瘴妖、巴豆火毒靈、甘遂水蠱精）。擊殺後掉落真實藥材與解毒方（附帶簡短藥典提示），並蒐集「生薑、甘草、綠豆」補給。
- **轉（煉毒骨壇 — Boss 戰：生川烏・烏頭魔尊）**：
  - **第一階段（生品大毒）**：魔尊身披「雙酯型烏頭鹼」紫黑毒甲，使出橫掃、心悸衝擊波與遠程毒棘。玩家需善用閃避、格擋彈反與**「文火久煎訣」**（炮製技能）破除其生毒護甲。
  - **第二階段（狂暴反噬）**：血量低於 50% 時魔尊怒吼，召喚「馬錢子痙攣陣」（地面法陣預警）與「烏頭連斬」。玩家藉炮製破勢、以生薑甘草湯解毒，最終將其斬落並煉化為回陽救逆的**炮製熟附子**。
- **合（尋藥歸途 — 本草復盤）**：戰勝後瘴氣散去，月光灑滿山谷。結算畫面呈現本次戰鬥中解鎖的《毒劇中藥材安全圖鑑》（含毒性分級、炮製原理、解毒方式與臺灣禁用品項回顧）。

## 四、操作與戰鬥手感設計

沿用 `guizang-game-skill` 的 `scripts/input.js`（防丟鍵 + `F3` 除錯面板）與自測鉤子（`G.step`、`G.upd`、`G.press`、`?auto`、`?god`、`?stage=boss`）：

- **移動**：`W / A / S / D`（斜俯視角相機方向對齊）
- **輕擊（赭鞭三段連招）**：滑鼠左鍵 或 `J`（附帶攻擊吸附、逐角色頓幀、火花沿揮砍方向飛散）
- **閃避（翻滾無敵幀）**：`Space` 或 `Shift`（最高優先級，可隨時打斷攻擊與格擋）
- **格擋／彈反**：滑鼠右鍵 或 `K`（舉鞭 0.24 秒內接招觸發「彈反」，不耗體力並開啟 0.85 秒處決反擊窗口）
- **技能 1「文火久煎訣（炮製）」**：`Q`（釋放金紅藥鼎火陣，對毒劇怪造成高額破甲／減毒效果）
- **大招「神農百草印」**：`R`（蓄滿後施放，水墨法陣展開、落劍／藥印連擊、淨化自身中毒狀態）
- **飲用解毒湯藥**：`E`（消耗採集到的對症解毒湯，回血並清除中毒；提示「先起如黍栗，不可過量」）
- **本草圖鑑／暫停**：`Tab` 或 `Esc`

## 五、無付費工具的零成本素材策略

由於目前沒有 Tripo / 即夢 / Suno，為避免做出「方塊灰模 + 刺耳蜂鳴」的廉價感，本作採用以下策略：
1. **水墨國風著色器（核心顏值來源）**：自寫 GLSL 地面著色器（融合青苔、碎石、枯草、薄霧與積水反光）、實例化隨風起伏的萬叢枯草與毒草、分層體積霧與月光泛光（控制 HDR 峰值在 2–3 防過曝）。
2. **精細風格化骨骼模型**：主角（道袍、斗笠、披風、赭鞭、藥鼎）、小怪與 Boss 皆以多關節層級骨架＋流線幾何雕刻構成，搭配雙段 IK 姿態解算與動作關鍵幀（蓄力、揮鞭、受擊、翻滾、Boss 砸地），並加上動態光軌與墨跡特效。
3. **聲音系統**：以 Web Audio API 實作「多層質感音效」（低頻衝擊 + 濾波噪聲揮鞭 + 金屬泛音彈反鐘聲 + 敲鐘式掉落提示音），搭配五聲音階古風程序配樂（探索／小怪戰／Boss 戰三段交叉淡入），並**預留 `assets/music/*.mp3` 與 `assets/sfx/*.ogg` 接口**，日後只要丟入音檔即自動取代。
